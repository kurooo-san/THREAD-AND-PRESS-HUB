THREAD & PRESS HUB - PROJECT SUMMARY
====================================
E-commerce platform for apparel and custom printed designs, with AI features.
Updated 2026-10-09. Details: README.md and docs/SYSTEM_ARCHITECTURE.md.

STACK
- PHP 8 (procedural) + MySQL/MariaDB, Apache
- Bootstrap 5, vanilla JavaScript, Three.js (3D preview), Chart.js
- Google Gemini (gemini-2.5-flash, gemini-2.5-flash-image)
- PayMongo hosted checkout (GCash, Maya, GrabPay, card) + Cash on Delivery / Pickup
- Brevo email API (Railway) / PHPMailer SMTP (local), Dompdf invoices, built-in Excel writer
- Installable PWA; live on Railway (Docker), developed on XAMPP

CUSTOMER FEATURES
- Browse as a guest; sign in to add to cart (the add finishes after login)
- Shop filters, Quick Add, Buy Now, cart, reviews, saved addresses (up to 3)
- Checkout: delivery fee by area, PWD/Senior 20% discount, vouchers
  (best one auto-picked), 12% VAT, PayMongo or cash
- My Vouchers wallet: vouchers given by the shop, no codes to type
- Order tracking that updates live when the shop changes the status; PDF invoices
- Design Studio: 2D canvas + live 3D model, templates, sleeves, logo spot,
  AI artwork; custom order, payment and tracking
- Virtual Try-On, AI Stylist and size finder
- One chat window: AI Assistant + Live Support, with AI-to-human handoff
  (the AI chat is attached so the customer does not repeat themselves)
- Email updates: welcome, orders, status changes, vouchers, password reset

ADMIN FEATURES
- Dashboard with KPIs and charts
- Products (with AI Product Generator), stock
- Orders: status changes and Verify/Reject payment save without reloading;
  cancelling an order returns its vouchers
- Coupons: create, edit, activate, delete, and Give as vouchers
  (selected customers or all, with a gift note)
- Sales Report for any date range: Print and Excel export
- Custom designs and custom orders
- Support Chat with AI Suggest Reply; Contact messages; Chatbot FAQ
- AI Insights (read-only questions about sales, stock, discounts)
- Audit Log

AI FEATURES (Google Gemini, keys server-side only)
1. AI Chatbot (store-aware, knows the customer's own orders and vouchers, hands off to staff)
2. Virtual Try-On + AI Stylist
3. AI Design Generator (Design Studio)
4. AI Product Generator (admin approves before saving)
5. AI Insights and Suggest Reply (admin)
Hourly per-customer limits (ai_usage table); admins unlimited.

DATABASE
- threadpresshub: 25 tables in database/schema.sql, plus ai_usage and
  user_coupons created on first use. ERD: docs/system-architecture/ERD.png

SECURITY
- bcrypt passwords, one strong-password rule, login rate limiting
- CSRF tokens on every form and AJAX write; admin check on every admin page
- Prepared statements; order + stock + voucher in one transaction
- Prices and vouchers re-checked on the server; PayMongo webhook signature
- Uploads checked by real file type, 5MB limit, random names
- Audit log of important actions

TESTS
- PHPUnit: helpers, coupon/voucher rules, size estimate, password rule
  (php vendor/bin/phpunit)
