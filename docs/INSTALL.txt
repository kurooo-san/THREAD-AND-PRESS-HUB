Thread & Press Hub - Installation
=================================

The full, current guide is docs/SETUP_GUIDE.md. Short version:

REQUIREMENTS
- XAMPP with PHP 8.0+ (mysqli, gd, fileinfo, zip, mbstring) and MySQL/MariaDB
- Composer

STEPS
1. Put the project in C:\xampp\htdocs\thread-and-presshub\
2. In that folder run:  composer install
3. Start Apache and MySQL in XAMPP.
4. In phpMyAdmin (http://localhost/phpmyadmin) create the database
   "threadpresshub" and import database/schema.sql (25 tables).
   The app creates ai_usage and user_coupons by itself on first use.
5. Copy .env.example to .env and fill in GEMINI_API_KEY, the PAYMONGO_* keys
   and BREVO_API_KEY or SMTP_* as needed. Database defaults work on XAMPP.
6. Register an account, then set its user_type to "admin" in the users table.
7. Open http://localhost/thread-and-presshub/

TESTS
  php vendor/bin/phpunit

LIVE SITE
  Railway, built from the Dockerfile. See docs/PRODUCTION_DEPLOYMENT.md.
